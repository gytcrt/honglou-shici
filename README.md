# 红楼诗词

**https://honglou.andreagao.com/**

[![红楼诗词](og/site.png)](https://honglou.andreagao.com/)

脂本《红楼梦》前八十回的全部韵语（诗、词、曲、赋、联、谜、令、判词），每首一页，附前后文、脂批和注释。纯静态网站，由 GitHub Pages 托管。

## 来源

- 正文：吴铭恩《红楼梦脂评汇校本》（简体），以庚辰本为底本汇校各脂本。
- 脂批：同上，每条标注所出抄本与位置。
- 注释：蔡义江《红楼梦诗词曲赋全解》（复旦大学出版社）各篇的字词注释，按原书标号挂在相应诗句上，每页注明页码。
- 字体：京华老宋体（王廷瑞，v2.002，作者声明可免费使用），网页字体切片来自中文网字计划；界面文字用思源黑体。

## 怎么读

按回目找，或者搜索诗句里的几个字，或者首页的“随便翻翻”。诗句旁的 ①② 是注释，红色的“脂”是该句的脂批，点一下展开。

## 维护

这是个人兴趣项目。本仓库只放生成好的网页；生成脚本和数据在另一个（私有）仓库里，更新时重新生成后整体同步到这里。

发现错字、错注，欢迎提 issue。
